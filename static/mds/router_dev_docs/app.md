# 主应用路由接口文档

## 文件路径
`app.py`

## 接口列表

### 1. 首页（通用）
- **路径**: `/`
- **方法**: `GET`
- **函数名**: `index`
- **描述**: 返回项目首页HTML页面

#### 请求参数
无

#### 请求示例
```
GET /
```

#### 响应示例（失败）
```json
{
    "code": 500,
    "msg": "服务器内部错误"
}
```

#### 响应格式
- **类型**: HTML

#### 响应示例
```html
<!DOCTYPE html>
<html>
...
</html>
```
