      ) 的前缀符号为圆圈，使用 .circle 类，实例如下:

        列表菜单

        一些 Web 页面可能需要列表菜单。

        在 HTML 中，列表菜单同无序列表

          来定义，例如:

          <ul>
            <li><a href="#">Home</a></li>
            <li><a href="#">Menu 1</a></li>
            <li><a href="#">Menu 2</a></li>
            <li><a href="#">Menu 3</a></li>
          </ul>

          结果:

          • Home
          • Menu 1
          • Menu 2
          • Menu 3
