jQuery EasyUI 数据网格 - 创建复杂工具栏

数据网格（datagrid）的工具栏（toolbar）可以包含按钮及其他组件。 您可以通个一个已存在的 DIV 标签来简单地定义工具栏布局，该 DIV 标签将成为数据网格（datagrid）工具栏的内容。 本教程将向您展示如何创建数据网格（datagrid）组件的复杂工具栏。

创建工具栏（Toolbar）

     id="tb" style="padding:5px;height:auto">
         style="margin-bottom:5px">
             href="#" class="easyui-linkbutton" iconCls="icon-add" plain="true">
             href="#" class="easyui-linkbutton" iconCls="icon-edit" plain="true">
             href="#" class="easyui-linkbutton" iconCls="icon-save" plain="true">
             href="#" class="easyui-linkbutton" iconCls="icon-cut" plain="true">
             href="#" class="easyui-linkbutton" iconCls="icon-remove" plain="true">
        
        
            Date From: class="easyui-datebox" style="width:80px">             To: class="easyui-datebox" style="width:80px">             Language:              class="easyui-combobox" style="width:100px"                     url="data/combobox_data.json"                     valueField="id" textField="text">              href="#" class="easyui-linkbutton" iconCls="icon-search">Search         
     

创建数据网格（DataGrid）

     class="easyui-datagrid" style="width:600px;height:250px"
            url="data/datagrid_data.json" 
            title="DataGrid - Complex Toolbar" toolbar="#tb"
            singleSelect="true" fitColumns="true">
        
            
                 field="itemid" width="60">Item ID
                 field="productid" width="80">Product ID
                 field="listprice" align="right" width="70">List Price
                 field="unitcost" align="right" width="70">Unit Cost
                 field="attr1" width="200">Address
                 field="status" width="50">Status
            
        
    

正如您所看到的，数据网格（datagrid）的工具栏域对话框（dialog）相似。我们不需要写任何的 javascript 代码，就能创建带有复杂工具栏的数据网格（datagrid）。
