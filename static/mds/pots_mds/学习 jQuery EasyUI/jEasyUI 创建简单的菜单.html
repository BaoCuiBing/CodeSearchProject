jQuery EasyUI 菜单与按钮 - 创建简单的菜单

菜单（Menu）定义在一些 DIV 标记中，如下所示：

     id="mm" class="easyui-menu" style="width:120px;">
         onclick="javascript:alert('new')">New
        
            Open              style="width:150px;">                 
Word
                 
Excel
                 
PowerPoint
             
         
         icon="icon-save">Save          class="menu-sep">         
Exit
     

当菜单创建之后是不显示的，调用 'show' 方法显示它或者调用 'hide' 方法隐藏它：

    $('#mm').menu('show', {
      left: 200,
      top: 100
    });
