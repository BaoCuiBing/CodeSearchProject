ionic 表单和输入框

list 类同样可以用于 input 元素。item-input 和 item 类指定了文本框及其标签。

输入框属性：placeholder

以下实例中，默认为100%宽度（左右两侧没有边框），并使用 placeholder 属性设置输入字段预期值的提示信息。 

 class="list">
   class="item item-input">
     type="text" placeholder="First Name">
  
   class="item item-input">
     type="text" placeholder="Last Name">
  
   class="item item-input">
     placeholder="Comments">

输入框属性：input-label

使用 input-label 将标签放置于输入框 input 的左侧。

 class="list">
   class="item item-input">
     class="input-label">用户名：
     type="text">
  
   class="item item-input">
     class="input-label">密码：
     type="password">

堆叠标签

堆叠标签通常位于输入框的头部。每个选项使用 item-stacked-label 类指定。 每个输入框需要指定 input-label。以下实例也使用了 placeholder 属性来设置信息输入提示。

 class="list">
   class="item item-input item-stacked-label">
     class="input-label">First Name
     type="text" placeholder="John">
  
   class="item item-input item-stacked-label">
     class="input-label">Last Name
     type="text" placeholder="Suhr">
  
   class="item item-input item-stacked-label">
     class="input-label">Email
     type="text" placeholder="john@suhr.com">

浮动标签

浮动标签类似于堆叠标签，但浮动标签有一个动画的效果，每个选项需要指定 item-floating-label 类，输入标签需要指定 input-label。

 class="list">
   class="item item-input item-floating-label">
     class="input-label">First Name
     type="text" placeholder="First Name">
  
   class="item item-input item-floating-label">
     class="input-label">Last Name
     type="text" placeholder="Last Name">
  
   class="item item-input item-floating-label">
     class="input-label">Email
     type="text" placeholder="Email">

内嵌表单

默认情况下每个输入域宽度都是100%，但我们可以使用 list list-inset 或 card 类设置表单的内边距(padding)， card 类带有阴影。

 class="list list-inset">
   class="item item-input">
     type="text" placeholder="First Name">
  
   class="item item-input">
     type="text" placeholder="Last Name">

尝试一下 »

内嵌输入域

使用 list-inset 设置内嵌实体列表。 使用 item-input-inset 样式可以内嵌一个按钮。 

 class="list">

   class="item item-input-inset">
     class="item-input-wrapper">
       type="text" placeholder="Email">
    
     class="button button-small">
      Submit

带图标的输入框

item-input 输入框可以很简单的添加图标。 图标可以在 前添加。

 class="list list-inset">
   class="item item-input">
     class="icon ion-search placeholder-icon">
     type="text" placeholder="Search">

头部输入框

输入框可放置在头部，并可添加提交或取消按钮。

 class="bar bar-header item-input-inset">
   class="item-input-wrapper">
     class="icon ion-ios-search placeholder-icon">
     type="search" placeholder="搜索">
  
   class="button button-clear">
    取消
