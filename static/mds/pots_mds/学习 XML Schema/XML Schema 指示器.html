XSD 指示器

通过指示器，我们可以控制在文档中使用元素的方式。

指示器

有七种指示器：

Order 指示器：

  • All
  • Choice
  • Sequence

Occurrence 指示器：

  • maxOccurs
  • minOccurs

Group 指示器：

  • Group name
  • attributeGroup name

Order 指示器

Order 指示器用于定义元素的顺序。

Occurrence 指示器

Occurrence 指示器用于定义某个元素出现的频率。

注意： 对于所有的 "Order" 和 "Group" 指示器（any、all、choice、sequence、group name 以及 group reference），其中的 maxOccurs 以及 minOccurs 的默认值均为 1。
