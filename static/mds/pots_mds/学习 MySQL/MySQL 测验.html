MySQL 测验

开始

MySQL中创建数据库的语句是？

  • NEW DATABASE database_name;
  • CREATE SCHEMA database_name;
  • MAKE DATABASE database_name;
  • CREATE DATABASE database_name;

如何选择要操作的数据库？

  • SELECT database_name;
  • USE database_name;
  • OPEN database_name;
  • CHOOSE database_name;

创建数据表的标准语句是什么？

  • MAKE TABLE table_name (...);
  • NEW TABLE table_name (...);
  • CREATE TABLE table_name (...);
  • BUILD TABLE table_name (...);

向数据表中插入数据的语句是？

  • ADD INTO table_name VALUES(...);
  • INPUT INTO table_name VALUES(...);
  • PUT INTO table_name VALUES(...);
  • INSERT INTO table_name VALUES(...);

从数据表中查询所有数据的语句是？

  • SEARCH * FROM table_name;
  • GET * FROM table_name;
  • SELECT * FROM table_name;
  • PICK * FROM table_name;

更新数据记录的语句是？

  • EDIT table_name SET column=value;
  • ALTER table_name SET column=value;
  • CHANGE table_name SET column=value;
  • UPDATE table_name SET column=value;

删除表中部分记录的语句是？

  • REMOVE FROM table_name WHERE condition;
  • DESTROY FROM table_name WHERE condition;
  • DELETE FROM table_name WHERE condition;
  • DROP FROM table_name WHERE condition;

删除整个数据表的语句是？

  • DELETE TABLE table_name;
  • REMOVE TABLE table_name;
  • DROP TABLE table_name;
  • ERASE TABLE table_name;

修改表结构（如新增、删除列）的语句使用哪个关键字？

  • UPDATE TABLE table_name ...;
  • ALTER TABLE table_name ...;
  • MODIFY TABLE table_name ...;
  • CHANGE TABLE table_name ...;

向数据表中添加新列的语句是？

  • INSERT TABLE table_name ADD column_name datatype;
  • MODIFY TABLE table_name ADD column_name datatype;
  • UPDATE TABLE table_name ADD column_name datatype;
  • ALTER TABLE table_name ADD column_name datatype;

删除数据表中某一列的语句是？

  • DELETE TABLE table_name DROP column_name;
  • REMOVE TABLE table_name DROP column_name;
  • ERASE TABLE table_name DROP column_name;
  • ALTER TABLE table_name DROP column_name;

获取当前日期的函数是？

  • NOW();
  • CURRENT_DATE();
  • GETDATE();
  • CURDATE();

对查询结果进行排序用到的关键字是？

  • SORT BY
  • ARRANGE BY
  • GROUP BY
  • ORDER BY

对查询结果进行分组用到的关键字是？

  • ORDER BY
  • CLUSTER BY
  • GROUP BY
  • PARTITION BY

统计数据条数的函数是？

  • SUM()
  • NUMBER()
  • COUNT()
  • TOTAL()

查询唯一记录时应使用的关键字是？

  • UNIQUE
  • DIFFERENT
  • DISTINCT
  • SEPARATE

数据类型 VARCHAR 表示？

  • 固定长度字符串
  • 数字型数据
  • 日期型数据
  • 可变长度字符串

内连接查询用到的关键字是？

  • LEFT JOIN
  • RIGHT JOIN
  • FULL JOIN
  • INNER JOIN

设置表中自增主键的属性是？

  • SERIAL
  • AUTO_ID
  • INCREMENTAL
  • AUTO_INCREMENT

向已存在的表添加主键的语句是？

  • MODIFY TABLE table_name ADD PRIMARY KEY (column);
  • UPDATE TABLE table_name ADD PRIMARY KEY (column);
  • INSERT INTO table_name ADD PRIMARY KEY (column);
  • ALTER TABLE table_name ADD PRIMARY KEY (column);
