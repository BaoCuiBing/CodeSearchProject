Vue.js 安装

1、独立版本

我们可以在 Vue.js 的官网上直接下载 vue.min.js 并用

我们把 js、css 路径修改为相对路径：

 href=static/css/app.33da80d69744798940b135da93bc7b98.css rel=stylesheet>
 type=text/javascript src=static/js/app.717bb358ddc19e181140.js>

这样直接双击 dist/index.html 文件就可以在浏览器中看到效果了。

编辑器

VS Code

VS Code（全称 Visual Studio Code）是一款由微软推出的免费、开源、跨平台的代码编辑器。

VS Code 支持 Windows、macOS 和 Linux，拥有强大的功能和灵活的扩展性。

VS Code 教程：https://www.runoob.com/vscode/vscode-tutorial.html
