现实生活中的 XML

如何使用 XML 来交换信息的一些实例。

实例：XML 新闻

XMLNews 是用于交换新闻和其他信息的规范。

对新闻的供求双方来说，通过使用这种标准，可以使各种类型的新闻信息通过不同软硬件以及编程语言进行的制作、接收和存档更加容易：




Colombia Earthquake



143 Dead in Colombia Earthquake


By Jared Kotler, Associated Press Writer


Bogota, Colombia
Monday January 25 1999 7:28 ET
