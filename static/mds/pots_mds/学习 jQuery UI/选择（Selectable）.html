jQuery UI 实例 - 选择（Selectable）

使用鼠标选择单个元素或一组元素。

如需了解更多有关 selectable 交互的细节，请查看 API 文档 可选择小部件（Selectable Widget）。

默认功能

在某个 DOM 元素上或者一组元素上启用 selectable 功能。通过鼠标拖拽选择条目。按住 Ctrl 键，选择多个不相邻的条目。
