简历结构设计

一份优秀的Markdown简历应该包含以下核心结构：

# 姓名
## 联系方式
## 职业目标/个人简介
## 工作经验
## 教育背景
## 技能清单
## 项目经历
## 其他信息

信息层次划分

Markdown 简历的信息层次应该遵循以下原则：

  1. 一级标题（#）: 姓名和职位
  2. 二级标题（##）: 主要板块（联系方式、工作经验等）
  3. 三级标题（###）: 具体职位或项目名称
  4. 四级标题（####）: 子项目或详细分类
  5. 粗体文本: 重要信息强调
  6. 列表: 技能点或职责描述
