jQuery Mobile 图标

我们可以使用图标类在 jQuery Mobile 中 和 尝试一下


在 按钮中添加图标，可以使用 data-icon 属性:


data-icon="refresh">刷新页面 尝试一下

我们可以使用 data-icon 属性在导航按钮上添加图标:


data-icon="refresh">刷新页面 尝试一下

如果要在列表按钮中添加图标，可以在

  • 中使用 data-icon 属性：


  • data-icon="refresh">点我
