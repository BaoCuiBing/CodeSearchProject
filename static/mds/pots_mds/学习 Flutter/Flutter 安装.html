Flutter 安装

在学习构建 Flutter 应用之前，需要先在本地机器上安装 Flutter SDK 及所有必需依赖项。本节将详细介绍在 Windows、macOS 和 Linux 系统上的安装步骤。

系统要求

在安装 Flutter 之前，请确保你的开发环境满足以下基本要求：

要求项WindowsmacOSLinux
操作系统Windows 10 或更高版本macOS 10.14 或更高版本Ubuntu 18.04 或更高版本
磁盘空间至少 2.8 GB至少 2.8 GB至少 2.8 GB
工具Git for WindowsGit (通过 Xcode)Git、curl、unzip

Windows 安装步骤

第一步：安装 Git for Windows

Git 是版本控制工具，Flutter 需要使用它来管理代码和下载 SDK。

  1. 访问 Git for Windows 下载页面
  2. 下载最新版本的 Git for Windows
  3. 运行安装程序，按照默认设置完成安装

第二步：安装 Visual Studio Code（推荐）

Visual Studio Code（简称 VS Code）是我们推荐的 Flutter 开发编辑器，它提供了丰富的 Flutter 扩展支持。

  1. 访问 VS Code 官网
  2. 下载并安装 VS Code
  3. 安装完成后，打开 VS Code

第三步：安装 Flutter SDK

有两种方式可以安装 Flutter SDK：

方式一：使用 VS Code 安装（推荐）

VS Code 的 Flutter 扩展可以自动下载和配置 Flutter SDK。

  1. 在 VS Code 中点击左侧扩展图标（或按 Ctrl+Shift+X）
  2. 搜索"Flutter"并找到"Dart and Flutter extensions"扩展
  3. 点击"Install"安装扩展
  4. 安装完成后，按 Ctrl+Shift+P 打开命令面板
  5. 输入"Flutter: New Project"并选择
  6. 选择"Download SDK"，然后选择安装目录

方式二：手动下载安装

  1. 访问 Flutter 官网下载页面
  2. 下载最新的 Flutter SDK（.zip 文件）
  3. 将下载的文件解压到你喜欢的目录，如 C:\flutter
  4. 将 Flutter 的 bin 目录添加到系统环境变量 PATH 中

手动配置环境变量

在 Windows 上配置环境变量的步骤：

  1. 右键点击"此电脑"，选择"属性"
  2. 点击"高级系统设置"
  3. 点击"环境变量"
  4. 在"系统变量"中找到 Path，点击"编辑"
  5. 点击"新建"，添加 Flutter 的 bin 目录路径（如 C:\flutter\bin）
  6. 点击确定保存

macOS 安装步骤

第一步：安装 Git

macOS 通常已经预装了 Git，你可以通过以下命令检查：

$ git --version

如果没有安装，运行以下命令：

$ xcode-select --install

弹出对话框后，点击"安装"按钮。

第二步：安装 VS Code

从 VS Code 官网 下载并安装 VS Code。

第三步：安装 Flutter SDK

与 Windows 类似，你可以选择从 VS Code 安装或手动安装。

手动安装步骤：

  1. 下载 Flutter SDK：
$ git clone https://github.com/flutter/flutter.git -b stable
  1. 将 Flutter 添加到 PATH：
$ echo 'export PATH="$PATH:/Users/你的用户名/flutter/bin"' >> ~/.zshrc
$ source ~/.zshrc

Linux 安装步骤

第一步：安装必要工具

在 Ubuntu/Debian 系统上，运行以下命令安装必要的工具：

$ sudo apt-get update
$ sudo apt-get install -y curl git unzip xz-utils zip libglu1-mesa

第二步：克隆 Flutter SDK

$ git clone https://github.com/flutter/flutter.git -b stable

第三步：配置 PATH

$ echo 'export PATH="$PATH:$HOME/flutter/bin"' >> ~/.bashrc
$ source ~/.bashrc

验证安装

无论你使用哪种操作系统安装 Flutter，都可以通过以下命令验证安装是否成功：

$ flutter doctor

运行此命令后，Flutter 会检查你的开发环境并报告问题。如果安装成功，你将看到类似以下的输出：

Doctor summary (v3.x.x):
[✓] Flutter (Channel stable, 3.x.x)
[✓] Android toolchain
[✓] iOS toolchain
[✓] Chrome (for web development)
[✓] Windows toolchain
[✓] macOS toolchain
[✓] Linux toolchain
[✓] Web server

初次运行 flutter doctor 时，它会下载 Dart SDK 并进行一些初始化操作，可能需要几分钟时间。

常见问题解决

Flutter 命令找不到

如果在终端中输入 flutter 命令显示找不到，请检查：

  • 环境变量 PATH 是否正确配置
  • 是否打开新的终端窗口（环境变量更改需要新窗口生效）

Android Studio 未安装警告

运行 flutter doctor 时可能会显示 Android Studio 未安装的警告。如果你不开发 Android 应用，这个警告可以忽略。

Android SDK 问题

如果需要开发 Android 应用但遇到 SDK 问题，可以：

  1. 下载并安装 Android Studio
  2. 在 Android Studio 中通过 SDK Manager 安装 Android SDK
