Vue3 内置属性

在 Vue.js 中，is、key 和 ref 是三个常用的内置属性，用法如下。

属性 核心作用 用法/示例
is 解决 HTML 标签语法限制，动态指定渲染的组件/原生标签

<标签 is="组件名">

     is="my-component">
key 给 Vue 虚拟DOM唯一标识，提升列表渲染效率，保证组件状态正确 <标签 key="唯一值">
<标签 :key="item.id"> 
 v-for="item in list" :key="item.id">{{item}}
ref 获取DOM元素或组件实例，用于直接操作原生DOM/调用子组件方法 模板：ref="名称"
脚本：this.$refs.名称 
 ref="inputRef">
this.$refs.inputRef.focus()

is 属性

在 Vue.js 中，is 属性通常用于动态组件的实现，特别是当你希望在运行时动态地切换不同的组件时非常有用。

  • 类型: String 或 Object
  • 作用: is 属性用于动态地指定当前 组件应该渲染哪一个子组件。通常结合 元素和动态组件的特性一起使用，允许你在运行时基于数据来切换不同的组件。
