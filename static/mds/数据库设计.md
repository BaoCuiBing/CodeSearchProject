# 数据库设计文档

## 用户表 (users)
| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| id | BIGINT | - | 否 | 自增 | 主键 |
| usernumber | VARCHAR | 50 | 否 | - | 账号 |
| username | VARCHAR | 50 | 否 | - | 用户名 |
| password | VARCHAR | 255 | 否 | - | 密码(明文存储) |
| email | VARCHAR | 100 | 是 | NULL | 邮箱 |
| created_at | DATETIME | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | 否 | CURRENT_TIMESTAMP | 更新时间 |

## 文件存储表 (files)
| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| id | BIGINT | - | 否 | 自增 | 主键 |
| user_id | BIGINT | - | 否 | - | 外键,关联users表 |
| filename | VARCHAR | 255 | 否 | - | 文件名 |
| file_path | VARCHAR | 500 | 否 | - | 文件存储路径 |
| file_size | BIGINT | - | 是 | 0 | 文件大小(字节) |
| file_type | VARCHAR | 50 | 是 | NULL | 文件类型 |
| file_url | VARCHAR | 500 | 否 | - | 文件访问链接 |
| created_at | DATETIME | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
