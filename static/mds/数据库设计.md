# 数据库设计文档

## 用户表 (users)
| 字段名 | 类型 | 长度 | 是否为空 | 默认值 | 说明 |
|--------|------|------|----------|--------|------|
| id | BIGINT | - | 否 | 自增 | 主键 |
| usernumber | VARCHAR | 50 | 否 | - | 账号(唯一索引) |
| username | VARCHAR | 50 | 否 | - | 用户名 |
| password | VARCHAR | 255 | 否 | - | 密码(加密存储) |
| salt | VARCHAR | 64 | 否 | - | 密码盐 |
| email | VARCHAR | 100 | 是 | NULL | 邮箱 |
| phone | VARCHAR | 20 | 是 | NULL | 手机号 |
| role | VARCHAR | 20 | 否 | user | 角色：user/admin |
| avatar | VARCHAR | 500 | 是 | NULL | 头像URL |
| bio | TEXT | - | 是 | NULL | 个人简介 |
| location | VARCHAR | 100 | 是 | NULL | 所在地 |
| website | VARCHAR | 200 | 是 | NULL | 个人网站 |
| github | VARCHAR | 200 | 是 | NULL | GitHub地址 |
| status | VARCHAR | 20 | 否 | active | 状态：active-正常,banned-封禁 |
| is_verified | TINYINT | - | 否 | 0 | 是否认证：0-否,1-是 |
| ban_reason | VARCHAR | 500 | 是 | NULL | 封禁原因 |
| ban_expire_time | DATETIME | - | 是 | NULL | 封禁过期时间 |
| last_login_time | DATETIME | - | 是 | NULL | 最后登录时间 |
| login_ip | VARCHAR | 50 | 是 | NULL | 登录IP |
| device_info | VARCHAR | 200 | 是 | NULL | 设备信息 |
| created_at | DATETIME | - | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | - | 否 | CURRENT_TIMESTAMP | 更新时间 |
