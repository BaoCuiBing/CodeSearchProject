# 项目文档

## 项目概述
CodeSearchProject是一个基于Sanic框架的代码搜索社区项目，支持文章发布、技术问答、代码搜索等功能。

## 技术栈
- 后端框架: Sanic 25.12.0
- 数据库: MySQL + SQLAlchemy 2.0.49 + PyMySQL
- 跨域支持: Sanic-Cors 2.2.0
- API文档: Sanic-OpenAPI
- 对象存储: 阿里云OSS

- 根目录：共用接口文档（upload_router.md、global_error_code.md、app.md）
