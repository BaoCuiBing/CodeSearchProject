# 项目文档

## 项目概述
CodeSearchProject是一个基于Sanic框架的代码搜索社区项目，支持文章发布、技术问答、代码搜索等功能。

## 技术栈
- 后端框架: Sanic 25.12.0
- 数据库: MySQL + SQLAlchemy 2.0.49 + PyMySQL
- 跨域支持: Sanic-Cors 2.2.0
- API文档: Sanic-OpenAPI

## 数据库设计
参考[数据库设计文档](数据库设计.md)，共17张数据表：
users、files、reports、search_history、categories、posts、tags、post_tags、comments、favorites、likes、follows、messages、system_messages、system_message_targets、system_settings、notifications

## API接口
路由开发文档位于 `static/mds/dev_docs/`，分为：
- `admin_router/`：管理后台API接口文档
- `app_router/`：APP端API接口文档
- 根目录：共用接口文档

## 启动方式
```bash
source .venv/bin/activate
python app.py
```

## 配置说明
在`config.py`中配置MySQL数据库连接信息。
