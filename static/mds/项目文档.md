# 项目文档

## 项目概述
CodeSearchProject是一个基于Sanic框架的代码搜索项目。

## 技术栈
- 后端框架: Sanic 25.12.0
- 数据库: MySQL + SQLAlchemy 2.0.49 + PyMySQL
- 跨域支持: Sanic-Cors 2.2.0

## 项目结构
```
CodeSearchProject/
├── app.py              # 应用入口
├── config.py           # 配置文件
├── requirements.txt    # 依赖列表
├── models/             # 数据库模型
│   ├── db_base.py      # 数据库基类
│   ├── db_init.py      # 数据库初始化
│   └── model.py        # 数据模型
└── static/             # 静态文件
    └── mds/            # 文档目录
```

## 数据库设计
参考[数据库设计文档](数据库设计.md)

## API接口
- `GET /` - 首页接口
- `GET /health` - 健康检查接口
- `GET /static/*` - 静态文件服务

## 启动方式
```bash
source .venv/bin/activate
python app.py
```

## 配置说明
在`config.py`中配置MySQL数据库连接信息。
