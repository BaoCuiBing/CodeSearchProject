# 项目文档

## 项目概述
CodeSearchProject是一个基于Sanic框架的代码搜索社区项目，支持文章发布、技术问答、代码搜索等功能。

## 技术栈
- 后端框架: Sanic 25.12.0
- 数据库: MySQL + SQLAlchemy 2.0.49 + PyMySQL
- 跨域支持: Sanic-Cors 2.2.0
- API文档: Sanic-OpenAPI

## 数据库设计
参考[数据库设计文档](数据库设计.md)，共17张数据表：
users、files、reports、search_history、categories、posts、tags、post_tags、comments、favorites、likes、follows、messages、system_messages、system_message_targets、system_settings、notifications

## API接口
路由开发文档位于 `static/mds/router_dev_docs/`，分为：
- `admin_router/`：管理后台API接口文档（12个）
- `app_router/`：APP端API接口文档（12个）
- 根目录：共用接口文档（upload_router.md、global_error_code.md、app.md）

## 前端API封装
- `static/webs/admin_pages/js/admin_request_api.js`：管理端API请求封装
- `App/src/assets/app_request_api.js`：APP端API请求封装（Vue格式）

## 前端页面组件
### 主页面
- `App/src/views/Main.vue`：首页（搜索、轮播、文章列表）
- `App/src/views/FaXian.vue`：发现页（分类、排行榜、推荐关注）
- `App/src/views/Message.vue`：消息页（系统通知、评论、点赞、关注）
- `App/src/views/MySelf.vue`：我的页（用户信息、菜单）

### 子页面
- `App/src/views/ShouYePages/ArticleDetail.vue`：文章详情页
- `App/src/views/FaXianPages/TagList.vue`：标签列表页
- `App/src/views/MessagePages/ChatDetail.vue`：聊天详情页
- `App/src/views/MySelfPages/UserProfile.vue`：用户资料编辑页

## 启动方式
```bash
source .venv/bin/activate
python app.py
```

## 配置说明
在`config.py`中配置MySQL数据库连接信息。
