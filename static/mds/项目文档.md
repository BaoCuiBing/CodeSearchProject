# 项目文档

## 项目概述
CodeSearchProject是一个基于Sanic框架的代码搜索社区项目，支持文章发布、技术问答、代码搜索等功能。

## 技术栈
- 后端框架: Sanic 25.12.0
- 数据库: MySQL + SQLAlchemy 2.0.49 + PyMySQL
- 跨域支持: Sanic-Cors 2.2.0
- API文档: Sanic-OpenAPI

## 项目结构
```
CodeSearchProject/
├── app.py              # 应用入口
├── config.py           # 配置文件
├── requirements.txt    # 依赖列表
├── models/             # 数据库模型
│   ├── db_base.py      # 数据库基类
│   ├── db_init.py      # 数据库初始化
│   └── model.py        # 数据模型（14个表）
├── router/             # 路由模块
│   ├── upload_router.py        # 文件上传（admin和app共用）
│   ├── admin_user_router.py    # 管理端用户路由
│   └── admin_view_router.py    # 管理端视图路由
├── static/             # 静态文件
│   └── mds/            # 文档目录
│       └── dev_docs/   # 路由开发文档
│           ├── admin_router/   # 管理端路由文档（11个）
│           └── app_router/     # APP端路由文档（9个）
└── test/               # 测试目录
```

## 数据库设计
参考[数据库设计文档](数据库设计.md)，共14张数据表：
users、files、reports、search_history、categories、posts、tags、post_tags、comments、favorites、likes、follows、messages、notifications

## API接口
路由开发文档位于 `static/mds/dev_docs/`，分为：
- `admin_router/`：管理后台API接口文档
- `app_router/`：APP端API接口文档
- 根目录：共用接口文档

## 启动方式
```bash
source .venv/bin/activate
python app.py
```

## 配置说明
在`config.py`中配置MySQL数据库连接信息。
